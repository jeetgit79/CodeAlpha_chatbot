# CodeAlpha_chatbot

A simple rule-based chatbot built using Python that interacts with users through text-based conversations.

Features

- Interactive text-based conversation
- Responds to predefined questions and commands
- Uses Python functions, loops, and conditional statements
- Beginner-friendly and easy to understand

Technologies

- Python
- Conditional Statements
- Functions
- Loops
- String Handling

Purpose

This project was created to practice Python programming, logical thinking, and basic chatbot development.
